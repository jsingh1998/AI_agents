# **🌟 Financial Agentic AI: Your Trusted Stock Market Ally 🌟**

**Financial Agentic AI** revolutionizes financial analysis by leveraging advanced AI technology and real-time web search capabilities. This sophisticated multi-agent system delivers accurate, actionable, and up-to-date stock market insights, tailored specifically to your requirements.

---

## **✨ Key Features**

- **🤖 Specialized AI Agents**: A dedicated team of AI agents focused on delivering precise and comprehensive insights.
- **📊 Deep Financial Analysis**: Gain access to stock prices, company updates, analyst recommendations, and historical market trends with powerful tools.
- **🌐 Real-Time Web Search**: Stay updated with live data from Google Search and DuckDuckGo, ensuring comprehensive market coverage.
- **📈 Unified Platform**: Seamlessly integrate financial data and web intelligence to empower your stock market decisions.

---

## **🔧 Functionality Overview**

### **1. Web Search Agent**
- **Objective**: Searches the web for timely, relevant information.
- **Tools Utilized**:
  - **Google Search**: Provides consistent results in a fixed language format.
  - **DuckDuckGo**: Focuses on privacy-conscious searches with tailored query results.
- **Features**:
  - Transparent reporting with source citations.
  - Markdown-formatted results for improved readability.

### **2. Financial Insights Agent**
- **Objective**: Conducts in-depth financial market analysis.
- **Tools Utilized**:
  - **YFinanceTools**: Tracks stock prices, news, analyst opinions, and historical data.
- **Features**:
  - Delivers structured insights through tables and charts.
  - Combines data visualization with clear textual summaries.

### **3. Multi-Agent Collaboration**
- **Objective**: Integrates insights from Web Search and Financial Insights agents.
- **Features**:
  - Provides a comprehensive stock market overview.
  - Offers multi-faceted answers to complex queries for informed decision-making.

---

## **🔍 Operational Workflow**

1. **Agent-Based Framework**:
   - Employs the `phi.agent` system to create highly specialized AI agents.

2. **Live Data Integration**:
   - Fetches real-time financial and web information via APIs.

3. **Interactive User Experience**:
   - Delivers enriched responses with tables, Markdown formatting, and verified sources.

4. **Example Query**:
   - **User Input**: "Provide the latest Nvidia news and summarize analyst opinions."
   - **Output**: A detailed table showcasing analyst sentiment, news highlights, and real-time updates.

## **🚀 Quickstart Guide**

### **Step 1: Clone the Repository**
```bash
git clone https://github.com/yourusername/financial-agentic-ai.git
cd financial-agentic-ai
```

### **Step 2: Install Dependencies**
```bash
pip install -r requirements.txt
```

### **Step 3: Configure Environment Variables**
- Create a `.env` file with the following content:
  ```env
  GROQ_API_KEY=your_groq_api_key
  ```

### **Step 4: Run the Application**
```bash
python financial_agent.py
```

### **Step 5: Access the Deployed App**
Visit the live deployment here: [Financial Agentic AI](https://jasvinder-fin-agent.streamlit.app/)
